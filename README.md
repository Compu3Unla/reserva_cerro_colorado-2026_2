# Cerro Colorado - Grupo 1

## Descripción del proyecto
Este proyecto consiste en traducir una maqueta de diseño generada en Figma a código web utilizando **HTML5** y **CSS**. El trabajo fue desarrollado para la materia **Computación 3** (Licenciatura en Diseño y Comunicación Visual - UNLa), con el objetivo de demostrar los conocimientos adquiridos en prototipado y aplicar un diseño *responsive* adaptable a distintas resoluciones de pantalla.

## Maqueta en Figma
* [Ver diseño en Figma - G1 Cerro Colorado](https://www.figma.com/design/NM2tqSUOeg9hftS4vTPv4g/G1---Cerro-Colorado?node-id=500-177&t=MegIG0QlOTwvTCdC-1)

## Herramientas utilizadas
* **Prototipado y diseño:** Figma
* **Desarrollo y maquetado:** HTML5 y CSS3
* **Editor de código:** Visual Studio Code

## Integrantes y resoluciones de trabajo
* **Arce, Candela** — Pantalla: `1920 × 1080 px`
* **Carro, Maia** — Pantalla: `1920 × 1080 px`
* **Hormaechea, Lara** — Pantalla: `1920 × 1080 px`
* **Tevez, Lourdes** — Pantalla: `1440 × 900 px`
